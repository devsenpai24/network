### BUG-001 — `_header()` comment triggered "allowed vlan all" test failure
**Discovered:** 2026-11-11 — first pytest run  
**Module:** `configgen.py`  
**Symptom:** `test_no_allowed_vlan_all_campus/metro/wan` all failed because the test checks `cfg.lower()` for the substring `"allowed vlan all"`, which appeared verbatim inside the warning comment: `! Generated by NetArchitect — do NOT use 'allowed vlan all'`.  
**Root Cause:** The header comment included the exact prohibited phrase as a human-readable reminder. The test lowercases the entire config string before checking, so the comment was caught.  
**Fix:** Rephrased the header comment to `"explicit VLAN lists required on all trunks"` — same intent, without the prohibited substring.  
**Test Updated:** `test_no_allowed_vlan_all_campus`, `test_no_allowed_vlan_all_metro`, `test_no_allowed_vlan_all_wan` — all now pass.
